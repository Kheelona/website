## Gotchas this round taught (all law'd in §8.22 / qa-report)

1. **Pixels carry claims**: og.png shipped a retired age band through three copy rounds because
   voice-lint reads HTML, not images. Check og/posters whenever copy laws change.
2. `next start`'s optimizer cache (`.next/cache/images`) survives rebuilds — stale variants for
   same-named replaced files. Vercel deploys are immune.
3. Hidden tabs freeze IntersectionObserver reveals AND defer media/lazy-image loading — the 3D
   visible-window QA law covers ALL reveal/media verification. (AudioMoments' 4s hang-fold arms
   only in visible tabs for this reason.)
4. A 404'd `<audio>` can hang at NETWORK_LOADING without firing `error` (§8.22-f).
5. A stale `next start` from an old session can squat :3456 serving the previous build — check
   `lsof -iTCP:3456` before trusting it.
