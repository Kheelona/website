# Round 2: four immersive directions (2026-07-08)

The ground-up redesign round. Same locked copy, same tokens, same beats; four different worlds. Each file is a full-scroll interactive mock-up of Home plus a preview of `/products/lumi` in that direction and its navigation model. The dashed purple **[ 3D ]** chips describe exactly what the live React Three Fiber scene does at each beat; a button bottom-left hides them. Every file cross-links to the other three at the top.

**How to view:** open each file in Chrome (the scroll-linked color and motion use Chrome's scroll-driven animations; other browsers show a static-but-complete version). Scroll slowly. Hover things: mascots, shapes, story cards.

| File | Direction | One-line pitch |
|---|---|---|
| `direction-1-world.html` | **Lumi's World** (the journey) | One continuous dreamscape; scrolling is a slow camera walk and every beat is a place along the path, ending at an orange sunset. The most cinematic. |
| `direction-2-day.html` | **A Day with Lumi** (the conversation) | The camera never moves; the mascot and Lumi live on one stage while the light passes through a whole day, dawn to lamplight. The most intimate; ends dark by design. |
| `direction-3-playmat.html` | **The Playmat** (the tabletop) | A bright endless play mat seen from above, scattered with chunky toy shapes you can nudge; content lies on cards among the toys. The cleanest and most modern. |
| `direction-4-popup-book.html` | **The Pop-up Storybook** (the storybook, reborn) | The storybook feel you liked, rebuilt natively: one pop-up book in a lamplit room, page-turns instead of section seams, paper-craft scenery rising from every fold. |

**What to judge:** the world metaphor, how the camera behaves, where the immersion comes from, and whether the page feels like ONE thing instead of stacked sections. Ignore polish-level details; everything visual here is a CSS approximation of the real WebGL scene.

**What is identical in all four (locked, not up for judging):** the verbatim copy, the beat order, the tokens and fonts, the Tally reserve finale, accessibility fallbacks (reduced motion gets a static site in all of them).

**Next step:** pick one (redlines welcome; mixing elements across directions is allowed if you say which). The build starts only after your pick. Model generation (`3d-handoff/README.md`) can run in parallel with your review.
