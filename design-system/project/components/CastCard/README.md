# CastCard

A portrait card for one member of the Kheelona cast: photo, name, age, city, home languages and a handwritten trait.

**Use it for:** internal decks, briefs and the cast page of this system. On the public site, use the cast inside layouts, not as "meet our kids" cards.

**Props:** `name`, `age`, `city`, `languages`, `line` (handwritten trait), `photo` (`*-portrait-web.webp` from the Cast group), `tone`, `alt`.

**Rules**
- The cast is fictional. Never use CastCard to present cast members as real customers.
- Keep the character sheet facts (age, city, languages) exactly as in **The cast**.
