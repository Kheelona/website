# Icon

76 Phosphor Bold icons drawn with `currentColor`, sized in `em`.

**Use it for:** buttons, chips, feature cards, app rows and status messages.

**Props:** `name` (see the grid; `Kheelona.ICON_NAMES` lists them all), `label` (makes it `role="img"` with an accessible name; otherwise it's hidden from screen readers), `className`, `style`.

**Rules**
- Use Bold weight only, never mixed with other icon sets or weights.
- Sizes: `icon-s` 16, `icon-m` 20, `icon-l` 24, and 40 inside a brand-colour circle on cards.
- Never use icons that say "AI" (brains, chips, sparkles, robots). For statuses, always pair the icon with a word.
- For design tools, the Icons asset group has the same icons as SVG files in `ink-900`.
