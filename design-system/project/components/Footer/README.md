# Footer

The site footer on `surface-band`: the logo (40px), the promise line, "Designed by parents in Bengaluru", link columns and legal links.

**Use it for:** every kheelona.com page.

**Props:** `brand`, `promise` (default "Wake-word listening. No open internet. You see everything."), `made` (handwritten line, or `false`), `columns` (`{ title, links[] }`), `legal` (strings).

**Rules**
- The promise line stays verbatim. It is the brand's safety summary.
- Link refund, shipping and privacy in every footer.
