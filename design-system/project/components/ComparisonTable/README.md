# ComparisonTable

A fair comparison table with Kheelu's column highlighted in sun and checks in Kheelu Blue.

**Use it for:** "How Kheelu compares" against smart toys, phones/TV and ordinary toys.

**Props:** `columns` (headers), `usIndex` (default 0), `rows` (`{ label, values[] }`; values starting with "Yes" get a check, "No" gets a cross, anything else is neutral), `caption`, `firstColumn`.

**Rules**
- Be fair. Give competitors "Yes" where it's true (ordinary toys have no screens). Credibility sells.
- Never name competitor brands. Compare categories.
- Each cell shows a word as well as an icon. On phones the table scrolls sideways with the first column fixed.
