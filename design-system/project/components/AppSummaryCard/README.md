# AppSummaryCard

The parent app's "Today with Kheelu" card: minutes, new words, stories, the topics talked about, one shared activity and a link to the full conversation.

**Use it for:** the parent app home screen, and app screenshots in marketing (as an illustrative example, labelled as such).

**Props:** `title`, `date`, `stats` (up to 3 `{ num, label, tone? }`), `words`, `topics`, `tryTitle`, `tryText`, `link` (`{ href, label }`).

**Rules**
- Report what happened, without judging the child: "6 new words", never "below average".
- Suggest one "Try together tonight" idea at most, built from the child's own day.
- Nothing is sold on this card, ever.
