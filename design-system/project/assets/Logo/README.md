# Logo

The official Kheelona wordmark, flattened from kheelona.com/brand/kheelona-wordmark.svg in its own colours: Chilli, the logo's orange (#EF762F), for the K, e, e, o and a; Kheelu Blue, the logo's sky blue (#29A0D7), for the K's ear, h, l and n; a white star in the o. v5 had recoloured it to darker shades; v7 (9 Oct 2026) returned every file to the website's colours. All SVGs are single-layer paths with no masks, so they import cleanly into Figma, Keynote, PowerPoint and print tools.

| File | Use |
|---|---|
| `kheelona-logo.svg` | **Day**, the default: cream, white and light photos |
| `kheelona-logo-bedtime.svg` | **Bedtime**: night grounds, the chalkboard, dark photos. Since v7 it has the same colours as Day, which read on dark grounds (6.1:1+) |
| `kheelona-logo-sticker.svg` | Day colours on a white cut-out outline, for sunshine, chilli and blue blocks and busy photos |
| `kheelona-logo-ink.svg` | One colour (`ink-900`) for print, stamps and embossing |
| `kheelona-logo-chalk.svg` | All white, for photos and dark fills where colour would clash |
| `kheelona-mark.svg` | The K alone, for avatars and anywhere the logo would be under 20px tall |
| `kheelona-app-icon.svg` | The K on a cream rounded square |
| `app-icon-512.png`, `apple-touch-icon-180.png` | Full-bleed square icons (the OS rounds the corners) |
| `favicon-32.png`, `favicon-48.png` | Browser tab icons |
| `kheelona-logo@2x.png`, `-bedtime@2x.png`, `-sticker@2x.png` | 160px-tall PNGs for tools that can't take SVG |

**Rules:** keep clear space equal to the height of the K's ear on every side; minimum size 20px tall on screen and 6mm in print; never stretch, rotate, outline, add effects, swap the two colours, or place the full-colour logo directly on chilli or blue (use Sticker or Chalk). In code, use the `Logo` component.
