# Cast

The Kheelona cast: five children and Tara's two parents. They are fictional and AI-generated (Nano Banana Pro via ElevenLabs, 8 Oct 2026). Never present them as real customers. Full character sheets and rules are in **The cast**.

Each person comes in four files:

- `*-portrait.jpg`: the master, 4:5, about 1856×2304, film-look photo against a home wall. Use it as the identity reference when generating new scenes.
- `*-portrait-web.webp`: 1000px wide for websites and previews.
- `*-cutout.png`: transparent background, about 1100–1230px tall, for compositing.
- `*-sticker.png`: the cut-out with a white outline and soft shadow, flat at the bottom crop. Place it on the bottom edge of crayon blocks.
