# Shapes

Flat cut-paper shapes with slightly hand-cut edges, in the brand colours:

- **Kheelu Blue (`blue-500`, #29A0D7):** `cloud-blue`, `blob-blue`, `ribbon-blue`
- **Chilli (`chilli-500`, #EF762F):** `flower-chilli` (sunshine centre), `half-round-chilli`, `heart-chilli`
- **Sunshine (`sun-500`):** `sun-sun`, `star-sun`
- **Rainbow:** `rainbow-arch`, the one shape in Kheelu's ear colours and the only rainbow in layouts.

They go behind products and children as a soft stage. Use at most two per view, in one brand colour (plus the rainbow arch if you need it), never touching text. They may bleed off the edge. Never recolour them.
