# Making cast photos (step by step)

This is the exact method used to make the 25 photos in the **Photo library** in October 2026. It is written for AI agents and for anyone briefing one. Follow it in order and a new photo will match the others: the same faces, the same film look, the same rules. The general rules for every AI image are in **Making new assets (for agents)**; this page is the hands-on recipe for the cast.

**Before you start**

- **Look in the Photo library first** (in **The cast**). Make a new photo only when nothing there fits and it will be reused at least three times. A one-off campaign photo follows the same steps but is saved in the campaign folder, not added to the library.
- **Get a yes and a budget from the owner.** Every run spends ElevenLabs credits, so get an estimate first (step 4). For scale: the cast and the 25-photo library together cost about ₹2,065 in October 2026.
- **The hard rules still apply.** Only the seven cast members. Kheelu only from its reference photo, never from text. Home, studio or plain wall, never outdoors. Children fully and everyday-dressed. Nothing a careful parent would object to.

## 1. Plan the shot

Fill in a scene card before writing the prompt. It forces the decisions the prompt needs.

```
Child:       Tara               one hero child; parents appear only with Tara
Number:      tara-06            the next free number for that child
Title:       Sorting socks
Ratio:       4:5                4:5 social and web cards, 16:9 web heroes and slides,
                                9:16 Stories and Reels, 1:1 portraits and cut-outs
Kheelu:      yes                3 in 5 library photos have Kheelu
Parent:      none               or Meera or Arnab (Tara only)
Setting:     Home · bedroom floor by the window
Outfit:      new for this child, from the wardrobe line in the character sheet
Moment:      what the child does and feels, in one sentence
Text space:  where the headline goes: left third, right third, top, or none
Use:         where it will run
```

- **New outfit, new place.** Check the Photo library table in **The cast** so the child isn't in an outfit or room they already have. Think of a portrait studio: the same face, a different setting and outfit every time.
- **Settings:** `Home ·` a room in an upper-middle-class Indian apartment, `Studio ·` the warm-cream seamless sweep, or `Plain wall ·` one colour, for portraits and cut-outs.
- **Moments that worked:** a "why" at breakfast, rain at the balcony door, a bedtime cuddle, drawing, building, reading, homework, a festive evening, a parent laughing with the child.

## 2. Write the prompt

Every prompt has the same parts, in this order. Copy the blocks exactly as written; only the scene is new. References are numbered in the order you connect them in step 3.

```
Using the attached references:       ("reference" when there is only one)
- <child block>                      Reference 1, always
- <Kheelu block>                     Reference 2, only when Kheelu is in the shot
- <parent block>                     Reference 3, Tara scenes only

Create a new photo: <scene>

<style block>
```

### Writing the scene

One paragraph, in this order:

1. **Place and moment:** the room, the time of day, what is happening.
2. **Action and feeling:** what the hands are doing, and the expression.
3. **Kheelu:** where it is and how it is held: whole, facing the camera, tummy disc visible.
4. **Outfit:** colour, fabric and print, plus the character's signature detail.
5. **Light:** one window, which side, what time of day.
6. **Composition:** the ratio, where the child sits, and where the calm space for text is.

**Add these lines.** They come from the checks in October 2026. Only the first was in the library prompts, so watch the first results of the others.

- Open books, notebooks or paper in the shot: "the pages show soft illustrations and no readable words". The library used this line and text still appeared on two pages, so avoid open pages facing the camera when you can.
- Bookshelves: "the books show plain coloured spines only, with no covers facing out". Face-out covers came back with fake titles.
- Plain-wall portraits: "the plain wall fills the whole background, with no window or door frame in the shot".
- Hero shots: "eyes open, looking at Kheelu" (or at the camera, or the parent).
- Every prompt: "a full-bleed photo with no film border or frame edge". Four photos came back with a thin dark film frame.

## 3. Set up the flow

- **Tool:** the ElevenLabs Full Connector.
- **Model:** Google Nano Banana Pro, `gemini-3-pro-image`. It keeps a character's face consistent across shots and composes several references into one photo.
- **Settings:** `resolution: "2K"`, and `aspect_ratio` from the scene card (`4:5`, `16:9`, `9:16` or `1:1`).
- **Flow:** add new scenes to the photo-library flow ([ElevenLabs flow lFyNGM9BZuQmAaVydVfT](https://elevenlabs.io/app/flows/lFyNGM9BZuQmAaVydVfT)), which already has every reference as a node. ## 4. Generate

- First call `creative_run_flow_nodes` with `estimate_only: true` to see the credit cost, and check it against the budget.
- Then run it with `generations_count: 2`. Two takes per scene were enough for every library photo but one; use 4 only for a hard scene.
- Poll `creative_get_flow_run_status`, waiting the suggested seconds between calls, until every take is complete.
- Never run a node again just to retry: every run is charged.

## 5. Download the full-size masters

- `creative_get_flow_run_status` returns a `content_url` for each take: the full 2K master. The links expire after about two hours, so download them straight away.
- The 2K sizes are 1856×2304 for 4:5, 2752×1536 for 16:9, 1536×2752 for 9:16 and 2048×2048 for 1:1. Never review or ship the small previews.
- If your workspace can't reach the ElevenLabs storage host (the Cowork cloud workspace couldn't in October 2026), open each link in the desktop browser so it downloads to the Downloads folder, and take it from there.

## 6. Check every take at full size

**First, the face check.** `tools/photo/face_check.py` compares every face in a photo with the seven cast portraits:

```
python3 tools/photo/face_check.py tara-06-take1.png tara-06-take2.png --child tara
```

In the library, the kept photos scored 0.42 to 0.93 against their own child (median 0.67). Treat the score as a flag, not a verdict. The model scores young children close together (two kept photos scored slightly higher for Myra than for the right child), and it finds no face when a head is turned or resting on the floor (Advik 04). "Looks more like …" means reject, unless your own side-by-side check clearly disagrees.

**Then look, zoomed in, with the portrait and the character sheet open next to it:**

- [ ] **Same child:** face, skin tone, hair, age and the signature detail: Myra's yellow clip, Advik's cowlick, Ira's braid and bindi, Tara's curls and beauty mark, Kabir's round glasses and missing tooth.
- [ ] **Eyes** open, looking the same way. **Teeth** right for the age.
- [ ] **Hands:** five fingers each, believable grips, nothing fused or extra.
- [ ] **Kheelu** passes the anatomy table in **Kheelu, the product**: whole, in focus, tummy disc visible, rainbow ear lining and foot pads, grey nose, nothing added.
- [ ] **Parents** (Tara's scenes): Meera's or Arnab's face matches their portrait.
- [ ] **No text:** no readable or garbled words, letters or logos on books, labels, screens or clothes.
- [ ] **Film look:** matte skin with texture, one believable light source, gentle shadows, no glow or glare, no dark frame at the edges.
- [ ] **Setting:** home, studio sweep or plain wall; a plausible Indian home; nothing outdoors.
- [ ] **Clothes:** the outfit asked for, everyday and modest.
- [ ] **Composition:** the calm space for text is where the scene card said.

**What went wrong in October 2026, and what to do about it:**

| Problem | Seen in | What to do |
|---|---|---|
| Fake titles on face-out book covers | Dropped takes of Advik 01 and Ira 04 | Pick the other take; ask for plain spines |
| Garbled text on an open book page | Kept Tara 03 and Kabir 04 | Clean it up (step 7) or pick the other take |
| Eyes closed | Dropped takes of Advik 04 and Ira 03 | Drop the take |
| Face turned away or covered by a hand | Dropped takes of Myra 01 and Kabir 03 | Drop it for any hero use |
| A window or door edge in a plain-wall portrait | Dropped takes of Myra 05, Ira 05 and Kabir 05 | Drop it, or crop it out if the face stays centred |
| Thin dark film frame at the edges | Kept Advik 01, 03, 04 and 05 | Trimmed automatically on export (step 7) |
| Kheelu hidden, squashed or held like a prop | Dropped takes of Myra 02, Advik 03 and Tara 01 | Drop the take |
| No calm space for text, or the child crowded at the edge | Dropped takes of Advik 02, Kabir 01 and Kabir 02 | Drop it; say exactly where the child sits |
| A frown or a stiff smile | Dropped takes of Myra 04 and Advik 05 | Drop the take |
| Outdoor scenes (a park, a train, a beach) | Three scenes in the first plan | Never: home, studio or plain wall only |

## 7. Pick, clean up and export

- Keep the better take for each scene. If neither passes, change the prompt and run it again. Don't fix it in retouching.
- **Allowed clean-ups:** trimming a dark film frame, and blanking garbled text on paper (book pages, notebooks, labels). **Never** retouch a face, hands, body or Kheelu, change skin tone, or mirror the photo.
- **Garbled text on paper:** draw boxes around the text in pixels on the full-size master, then run:

```
python3 tools/photo/retouch_page_text.py master.png cleaned.png --low telea 980 1545 1215 1640
```

Use `--low paper --sat 45` instead when dark artwork borders the text on white paper. Compare before and after at 200%: the page should look like plain paper with the same grain as the rest of the photo.

- **Export** into the library format:

```
python3 tools/photo/export_photo.py cleaned.png tara-06-sorting-socks
```

It trims a film frame if there is one (the photo keeps its exact size) and writes `tara-06-sorting-socks.jpg` (full size, JPEG quality 90) and `tara-06-sorting-socks-web.webp` (1500px on the long edge) into `assets/Photo library/`.

The three scripts need Python 3 and `pip install opencv-python-headless numpy scipy pillow`. The face check downloads its two models (about 40 MB) the first time.

## 8. Add it to the library

1. **Name** it `<child>-<nn>-<scene>`: lowercase with hyphens, using the next number for that child.
2. **Upload** both files to the design system and add them to the Photo library group. **How to use this system** explains how, under "Changing the system".
3. **Describe** it: add a row to the Photo library table in **The cast** (ratio, Kheelu, setting, outfit, best for), and update the photo counts in the README and in `assets/Photo library/README.md`.
4. **Log** it: add an entry to `tools/photo/library-log.json` with the flow node, the kept generation ID, how many takes you reviewed and any clean-up.
5. **Publish** the design system, then copy the changed files to the local folder.
