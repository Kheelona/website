Using it in code

Load the tokens, the stylesheet, React 18 and the bundle, then use the components from window.Kheelona. Every prop is in project/components/index.d.ts.

<link rel="stylesheet" href="project/tokens.css">
<link rel="stylesheet" href="project/components/bundle.css">
<script src="site/runtime/react.production.min.js"></script>
<script src="site/runtime/react-dom.production.min.js"></script>
<script src="project/components/bundle.js"></script>
<script>
  var K = window.Kheelona, h = React.createElement;
  ReactDOM.createRoot(document.getElementById('root'))
    .render(h(K.Button, { variant: 'cta', href: 'https://store.kheelona.com' }, 'Pre-order Kheelu'));
</script>
