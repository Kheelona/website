# design-system/ is read-only

This is the new Kheelona design system exactly as delivered (v11, 10 Oct 2026). Other teams share
it, so a change here breaks their work (brief section 4.1).

- Never edit, move, rename, reformat or add a file here, by any tool or shell command.
- Derivatives that look identical (compressed, resized, WebP/AVIF, srcsets, subset fonts) are
  generated by a script into a folder OUTSIDE design-system/.
- If a page needs something the DS cannot express, compose it from DS parts; if that is
  impossible, log a gap in `wiki/design-system/gaps.md` and ask the founder. Never improvise.
- Integrity: `node scripts/ds-checksums.mjs` must pass (manifest: `wiki/design-system/manifest.md`).
- How to use it: `wiki/design-system/overview.md`, `component-map.md`, `tokens.md`, `motion.md`.
