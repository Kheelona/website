# Assets catalogue

Every image, film, font and icon the site uses: its single source, how it reaches the page, and where
it is used. **Check before adding any file.** Rules (brief §4.1, §9.12; [ADR-010](adr/ADR-010-media-pipeline.md)):

- A DS asset is referenced from **one place**: a static import from `@ds/assets/…` inside a media
  primitive. Never copy a DS file by hand; never write into `design-system/`.
- Derivatives are generated by `scripts/assets/*` (or by `next/image` at request time) and say so in a
  header or a row here.
- Non-DS media is allowed only where a decision allows it (films D040, app screens D044, team photos
  B24, the recognition marks G3, both D054 item 20; the Ideabaaz logo B29, unused since D054 item 7); the one non-DS colour is WhatsApp green (D050).
- `test/guards/asset-dupes.test.ts` fails on duplicate files and on byte-copies of DS files outside the
  generated folders.

Each task updates only its own rows (Task column). Pages use the same abbreviations as
[components](components.md).
