# Flipkart (2026-10-10): a gap, recorded

**Suggestions: not captured.** Flipkart's search box asks its `autosuggest` API by **POST**; both GET
forms tried answered **403**. The task allows GET only, so no suggestion data was taken. The search
results page itself is a plain GET and answered 200, but it carries no related-search or
suggestion block in its server data; it only says "Showing 1 – 40 of **9,024** results for
'learning toys for 3 year old'", which measures **supply, not demand**, and is not used.

**Signals that did surface.** Google autocomplete shows Indian shoppers adding the store's name to
age queries ("toys for 3 year old boy flipkart", "brain development toys flipkart", "talking toys
for kids flipkart"), in [google-autocomplete-in-2026-10-10.md](google-autocomplete-in-2026-10-10.md).

**To fill this gap:** a person typing seeds into Flipkart's search box and noting the suggestions,
or a Flipkart seller account's keyword tools. Neither is available to an agent under the Phase 1
rules.
