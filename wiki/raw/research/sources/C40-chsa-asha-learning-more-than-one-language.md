## Exact passage

> "Using multiple languages does not confuse children or cause speech or language delays."

**Paraphrased, the next sentence (not quoted):** having a strong foundation in one language supports
learning additional languages. The following paragraph says a real communication issue shows up in
all the languages a child uses, and to talk to a speech-language pathologist if concerned.

## What this source does and does not support

- Supports: a second language does not cause speech or language delays; a strong first language
  supports learning more languages (a general statement, no figures).
- Does NOT support "a head start on words in every language after" as a measured effect, nor any
  brain mechanism.
- Cite it as ASHA's consumer guidance (published by CHSA), linking the asha.org address, which
  redirects.
