Exporting a template to PNG

Open the artboard in a browser and screenshot it, or render it exactly at size from the command line with headless Chrome — replace the dimensions with the artboard's:

chrome --headless=new --screenshot=out.png --window-size=1080,1080 --hide-scrollbars social-square-1080.html

On macOS the binary lives at /Applications/Google Chrome.app/Contents/MacOS/Google Chrome.

Before you build

Three things to know

Some mascot art is thumbnail-sized

Nine poses are print-grade at 2000 px or more; eight exist only at around 256 px because that's all the source file ever contained. Check the table in assets/MANIFEST.md before committing a pose to print.

The logo SVGs are reconstructions

They were rebuilt from the source vector geometry and verified against the reference render. For print-critical work, request a one-time official SVG or EPS export.

The fonts are licensed, not owned

All three families are SIL Open Font License 1.1. Keep the OFL-*.txt files alongside the TTFs in any copy you pass on, and never sell the fonts by themselves.
